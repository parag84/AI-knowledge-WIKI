**As agents compress build and test, the bottleneck moves sideways to design, so the design-system rules you can encode for agents (tokens, color, accessibility, golden components) now decide output quality more than the agents do.**

## Top insights

1. As build and test compress, the bottleneck shifts upstream to requirements, downstream to release, and 'sideways' to parallel teams such as risk, compliance and design. One bank's color-scheme and colorblind-accessibility rules had to be encoded into the agents.
   - _Why it matters:_ A bank had to encode its color-scheme and colorblind-accessibility rules into agents, which puts design-system governance directly in the agent pipeline you design for.
   - Source: [What AI Coding Leaders Do Differently - Martin Harrysson, Shilpa Khatana & Prakhar Dixit, McKinsey](https://github.com/parag84/AI-knowledge-WIKI/blob/main/knowledge/videos/2026-11-08-what-ai-coding-leaders-do-differently-martin-harrysson-shilp.md)
2. Quality is dropping even per developer and per PR as code generation speeds up. The recommended fix is to feed agents curated 'golden examples' rather than the average of the codebase, and to encode standards at every PDLC checkpoint instead of relying on end-of-pipeline quality gates.
   - _Why it matters:_ Feeding agents curated 'golden examples' instead of the codebase average fits a design system's reference components and docs, and positions them as agent inputs.
   - Source: [What AI Coding Leaders Do Differently - Martin Harrysson, Shilpa Khatana & Prakhar Dixit, McKinsey](https://github.com/parag84/AI-knowledge-WIKI/blob/main/knowledge/videos/2026-11-08-what-ai-coding-leaders-do-differently-martin-harrysson-shilp.md)
3. Leading teams replace two-week Scrum sprints with Kanban-style one- to two-day loops in which agents run the 'night shift' and humans validate. Human review checkpoints are removed once confidence in a loop is established.
   - _Why it matters:_ Human checkpoints are removed once a loop earns trust, a concrete delegation and supervision pattern to model in AX approval and review UI.
   - Source: [What AI Coding Leaders Do Differently - Martin Harrysson, Shilpa Khatana & Prakhar Dixit, McKinsey](https://github.com/parag84/AI-knowledge-WIKI/blob/main/knowledge/videos/2026-11-08-what-ai-coding-leaders-do-differently-martin-harrysson-shilp.md)
4. Skill curation is now the hard part, not skill availability. One client found about 1,700 downloadable skills just for writing a PRD. Organizations should curate a handful that fit their context.
   - _Why it matters:_ With about 1,700 PRD skills available, curation is the real problem, which argues for a small, governed set of design-system and portal skills rather than open catalogs.
   - Source: [What AI Coding Leaders Do Differently - Martin Harrysson, Shilpa Khatana & Prakhar Dixit, McKinsey](https://github.com/parag84/AI-knowledge-WIKI/blob/main/knowledge/videos/2026-11-08-what-ai-coding-leaders-do-differently-martin-harrysson-shilp.md)
5. Measuring impact remains the least mature area. Some clients are experimenting with using AI to score the value and intent of work so they can direct tokens and resources to the highest-value items.
   - _Why it matters:_ AI scoring of the value and intent of work points to intent-driven prioritization surfaces, an open design problem in agent dashboards.
   - Source: [What AI Coding Leaders Do Differently - Martin Harrysson, Shilpa Khatana & Prakhar Dixit, McKinsey](https://github.com/parag84/AI-knowledge-WIKI/blob/main/knowledge/videos/2026-11-08-what-ai-coding-leaders-do-differently-martin-harrysson-shilp.md)

## Suggested experiments

- **Agent-readable design-system rules** (small): Turn your color tokens, contrast and colorblind-safe pairing rules into a short machine-readable rules file (for example AGENTS.md plus token JSON). Ask a coding agent to build two or three screens with and without it, then compare token and accessibility violations.
- **Golden-example pack for Lit components** (medium): Pick three to five exemplary Lit components (one form control, one composite, one AI chat or streaming element) and package them with usage notes as the agent's reference set. Generate a new component with and without the pack and review the API consistency, slots and token use.
- **Trust-graduated approval UI prototype** (medium): Prototype an approval component for agent tasks that shows a loop's track record and lets a user step from approving every run to spot-checking to auto-approval. Test it with two or three developers to see what evidence they need before removing a checkpoint.
