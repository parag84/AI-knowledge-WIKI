## Current best understanding

**Autonomy is earned, enforced and made legible (as of Nov 2026).** The dominant AX pattern is an autonomy ladder:

- Meta's on-call teammate runs L1 investigate → L2 draft with approval → L3 own low-criticality work.
- Factory moves from L1 to L4 based on a measured "regret-free merge rate".
- A staged rollout goes observe → propose → act-and-notify → autonomous, with snapshots and canaries.

All of these escalate ties and large blast-radius actions to humans. Approval has to be enforced structurally, not by prompt. That means a deterministic pause node (Google ADK), advisory tool results with holds, read-only pipelines with proposal cards, or separating decide, authorize and execute (Trustline's scoped token and model-invisible PIN entry). Reviewer trust comes from precision over recall (Block; Figma requires 70% correctness before its reviewer posts). It also comes from structured agent PRs that include provenance, screenshots, video, done and not-done lists, and four reviewer actions. Teams also review by risk tier (Anthropic, Nov 2026). Tool results need a third "unknown" state so agents don't retry or falsely claim success.

**Supervision UI is converging.** Common patterns:

- Show only the latest semantic step (Antigravity), and let users click into sub-agents or message them.
- Model sub-agents as separate chats and use host/client session snapshots with first-wins approvals (AHP, Microsoft).
- Give humans daily digests with one-tap approvals.
- Use a 70% HTML executive summary and video proof in Slack in place of code reading.
- Highlight visible diffs as agent edits land (Claude Sheets) and attach certified badges to charts (Claude Data).
- Respect latency thresholds: 1 s keeps the user's train of thought, about 10 s triggers a task switch, and the median coding-agent turn is 63 s. Acknowledge immediately and keep slow work off the hot path.
- In voice (GPT-Live, full duplex), stay silent unless asked.

For intent-driven design:

- Pick the response format by intent (text vs day card vs week card).
- Make surgical edits using client-sent plan snapshots.
- Workday's prototype predicts intent as the user types and renders task cards.
- Present concrete alternative interpretations when a request is ambiguous.
- Let users set scope by direct manipulation: spatial selection in Whiteboards, selection shared with the model via MCP apps, and @-mention of design-system components.

**Design-system and dev-portal surfaces are opening to agents.** Codex/ChatGPT plugin extensions are built on MCP apps. They add sidebars, side panels, composer @-mention search tools and native settings controls. The in-app browser's annotation API makes individual design-system components selectable and editable. WebMCP lets sites expose tools to the user's own agent. Treat CLIs, skill.md files, help text and error messages as the agent's interface, because agents follow stale docs literally. MCP i18n (SEP-2792, Accept-Language negotiation, expected end of March 2027) and enterprise-managed auth (EMA/ID-JAG, live in Claude) shape how localized, governed tool UIs will reach users.

## Latest active insights

- Roll out agent autonomy in stages: observe → propose → act-and-notify with human approval and postmortem trail → autonomous for small tasks with restore snapshots and canaries (e.g., 20% traffic) before 100%. Always escalate priority ties, repeated conflicts and large blast-radius actions to humans. ([Multi-Agent SRE: What Happens When Your Agents Want Opposite Things - Aditi Mewada, Apple](../videos/2026-11-22-multi-agent-sre-what-happens-when-your-agents-want-opposite.md), 2026-11-22, relevance 3/5)
- He stopped reading code in many cases and instead hooks into the agent's trajectory around the 70% point, before verification. There he prompts it to produce a short executive summary as a typeset HTML page, which keeps his understanding in sync with the agent. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)
- Human attention stays flat while agent activity grows exponentially. He sends a steady 120–190 prompts per day, and agent active time went from less than one working day to many times his working day. He started 141 repos but regularly maintains only 10–15, and friends report a similar pattern. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)
- Local models fail at tasks involving tools or hardware released after their training cutoff unless the harness gives them web search. Adding search let a local Qwen model change GPU fan RGB colors after it had failed without search. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- The agent asked explicit permission before running a seeding script, which loaded 41 canonical exercises into a Firestore exercises collection — an example of an approval gate for side-effecting actions. ([From prototype to real Firebase backend (no code)](../videos/2026-11-21-from-prototype-to-real-firebase-backend-no-code.md), 2026-11-21, relevance 3/5)
- Agent instructions about console UI drifted from the real Firebase Console (e.g., authentication now sits under Security, Firestore under Databases and storage), so guided flows must tolerate UI mismatch. ([From prototype to real Firebase backend (no code)](../videos/2026-11-21-from-prototype-to-real-firebase-backend-no-code.md), 2026-11-21, relevance 3/5)
- Ask the agent to give 'one step at a time' and wait for confirmation, which turns a long setup checklist into a paced, conversational human-in-the-loop guide. ([From prototype to real Firebase backend (no code)](../videos/2026-11-21-from-prototype-to-real-firebase-backend-no-code.md), 2026-11-21, relevance 3/5)
- Graceful degradation means falling back to a preloaded local Gemma when offline, for example browsing cached products and queueing cart items to sync later. Progressive enhancement means unlocking capabilities such as image-based search when the device has more VRAM. ([Web AI at the Edge: Local Vector Search, Gemma 4, & hybrid cloud routing](../videos/2026-11-20-web-ai-at-the-edge-local-vector-search-gemma-4-hybrid-cloud.md), 2026-11-20, relevance 4/5)
- The recommended hybrid flow runs a quick on-device benchmark first and delegates to the cloud if it fails. If it passes, the app still uses the cloud while the model downloads, then switches to local and can expose a toggle such as 'privacy mode now available' or an offline mode. ([Web AI at the Edge: Local Vector Search, Gemma 4, & hybrid cloud routing](../videos/2026-11-20-web-ai-at-the-edge-local-vector-search-gemma-4-hybrid-cloud.md), 2026-11-20, relevance 4/5)
- Trust in agent output comes from attaching provenance to the PR: the full conversation, the tools used, before and after screenshots, and a video of a verification agent clicking through the app in a browser. ([How to build an agent that builds the culture — Zach Bruggeman, Ramp](../videos/2026-11-20-how-to-build-an-agent-that-builds-the-culture-zach-bruggeman.md), 2026-11-20, relevance 4/5)
- Making every agent session public by default replaces formal AI training: people learn by watching teammates' sessions, and can even ask the agent to summarize how a colleague structures prompts or breaks down problems. ([How to build an agent that builds the culture — Zach Bruggeman, Ramp](../videos/2026-11-20-how-to-build-an-agent-that-builds-the-culture-zach-bruggeman.md), 2026-11-20, relevance 4/5)
- Keyword-triggered, single-turn guardrails that hard-stop and refer out fail vulnerable users (missed implicit danger, over-firing on a stubbed toe); GRIT's proposed Zuzie architecture classifies risk over several turns, stores risk metadata in state, routes to normal vs high-risk personas, explains handovers transparently and keeps the conversation going. ([20 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-20-20-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-20, relevance 4/5)
- Trustline (Korapay) separates deciding, authorizing and executing: the LLM only proposes a payment intent with a summary, the fare is held ~15 minutes, PIN entry happens in a WhatsApp Flow the model never sees, and a scoped Kora payment token (single merchant, amount bounds, signed) is required before settlement; payment states map to completed/pending/failed/unchanged-on-unknown. ([20 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-20-20-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-20, relevance 4/5)
- Tool results need a third state, 'unknown', alongside success/failed: when a write call returns no verifiable handle, reporting 'failed' makes agents retry (duplicate deployments, wasted tokens) and 'success' is a false claim. Write tools should return a unique ID for verification and agents should not retry immediately on failure. ([20 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-20-20-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-20, relevance 4/5)
- Not all content should be machine-translated by the model: legal text needs verbatim official-language sources (Irish takes precedence in Irish law) and creative text relies on human localization, so servers should decide per content type whether to ship official translations. ([20 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-20-20-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-20, relevance 4/5)
- MCP internationalization (SEP-2792) borrows HTTP Accept-Language/Content-Language negotiation: clients send the user's OS language preferences to every MCP server (header for HTTP, metadata for stdio) and servers reply with localized tool titles, MCP App UI and data where available. Approved by core maintainers; expected in the end-of-March release, with agent support around April. ([20 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-20-20-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-20, relevance 4/5)
- For small on-device models, avoid exposing 100+ tools; use contextual or hierarchical tool loading by domain, short categorical schemas, and a pre-routing classifier that calls a tool at high confidence (~0.85) and asks for clarification at low confidence. ([19 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-19-19-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-19, relevance 3/5)
- In the FHIR + MCP clinical demo, read-only MCP resources (missed-appointment policy, SMS templates, lab catalog, clinician directory) constrain the agent, and a communication request passes gates for authorization, consent and recipient validity, with an option for human review before sending. ([19 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-19-19-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-19, relevance 3/5)
- An agent's ability to act should not automatically confer authority to act; agentic standards should define scoped permissions, mandatory human-in-the-loop decisions, traceability of every action, and reversibility when systems fail. ([19 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-19-19-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-19, relevance 3/5)
- Splitting a codebase into agent-owned engine code and a human-owned 'spec/human' folder restores control. The human folder is linted, governed by rules for Claude, reads like English, and uses domain units such as meters instead of magic numbers. ([The Sweet Side of the Bitter Lesson — Thariq Shihipar, Independent](../videos/2026-11-19-the-sweet-side-of-the-bitter-lesson-thariq-shihipar-independ.md), 2026-11-19, relevance 4/5)
- Pure vibe coding caused loss of comprehension and flow: the model silently made many design decisions, such as whether a rock passes through a wall, its speed or its charge. The author no longer knew what his own characters did and made less progress. ([The Sweet Side of the Bitter Lesson — Thariq Shihipar, Independent](../videos/2026-11-19-the-sweet-side-of-the-bitter-lesson-thariq-shihipar-independ.md), 2026-11-19, relevance 4/5)
- Models' smooth interior means output format is no longer constrained: the same mockup can be produced as HTML, React, Swift or Figma's proprietary JSON with roughly equal quality. So choose formats for human needs, not model preference. ([The Sweet Side of the Bitter Lesson — Thariq Shihipar, Independent](../videos/2026-11-19-the-sweet-side-of-the-bitter-lesson-thariq-shihipar-independ.md), 2026-11-19, relevance 4/5)
- Verification should run as an inner loop within a turn (build, lint, type, runtime errors, headless browser exploration) and an outer loop between turns (visitor behaviour, automatic A/B tests, payment conversions) so agents optimise business outcomes, not just code. ([What it takes to set intelligence free — Fabian Hedin, CTO, Lovable](../videos/2026-11-19-what-it-takes-to-set-intelligence-free-fabian-hedin-cto-lova.md), 2026-11-19, relevance 4/5)
- Treat the agent's PR as a live object: a GitHub app feeds review comments and events back to rerun the agent, which re-applies all verification checks before committing, and autonomously rebases stale PRs because red agent PRs were closed by developers essentially 100% of the time. ([We Built AI Agents To Fix Security Findings in Production](../videos/2026-11-19-we-built-ai-agents-to-fix-security-findings-in-production.md), 2026-11-19, relevance 3/5)
- Agent PRs got closed until they matched team conventions; a structured PR with what was done, what was not done, files touched, a remediation summary table and reviewer guidance, plus team-configurable branch naming and ticket links, raised developer trust and merge rates. ([We Built AI Agents To Fix Security Findings in Production](../videos/2026-11-19-we-built-ai-agents-to-fix-security-findings-in-production.md), 2026-11-19, relevance 3/5)

## Open questions

- Will WebMCP and annotation extensibility become cross-vendor standards, or remain tied to ChatGPT/Codex surfaces? This decides whether to annotate Lit components now.
- How should agent-state UI converge: Antigravity's 'latest semantic step only' versus AHP's full sub-agent chats with exposed tool calls?
- What metric should gate autonomy promotion across products (regret-free merge rate, precision thresholds, track record per action), and how should it be shown to users?
- How will the 'unknown' tool-result state and scoped authorization tokens surface in standard approval/tool-call UI components?
- MCP is about 6x costlier and 5x slower than a CLI on hard tasks (Arize eval). Will that push developer portals toward agent-optimized CLIs over MCP for power users?
