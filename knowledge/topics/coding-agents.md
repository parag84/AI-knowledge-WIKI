# Coding agents

> AI coding assistants and agents (Claude Code, Codex, Gemini CLI, etc.), dev workflows.

_57 active · 0 stale · synthesis updated 2026-11-22_

## Current best understanding

**Supervision is becoming evidence-based UX (Nov 2026).** Leading teams no longer review agent code line by line. They review artifacts:
- **Devin** replies in Slack with a PR plus a video of the fix.
- **Ramp's Inspect** attaches provenance to each PR: the full conversation, the tools used, before/after screenshots and a browser walkthrough recorded by a verification agent.
- **Practitioners** trigger a typeset HTML executive summary around 70% of the way through a run, before verification, to stay in sync with the agent.

This matters because human attention stays flat while agent runtime grows. One user's P90 task time went from ~2.5 min on Opus 4.6 to 14+ min on current models. Opus 5.5 has run for 12 hours on a vague goal ("make it more fun") by self-evaluating through simulation. Design-system tooling is converging with agent harnesses:
- **Codex plugin extensions** (Nov 2026) add sidebars, panels and composer behaviour. A design-system browser plugin injects component context through @-mentions.
- **Codex annotations API** makes individual design-system components selectable in annotate mode.
- **Appshots** capture a screenshot plus the page's accessibility tree.
- **Per-component dev inspector routes** render a component standalone with presets for AI states (thinking, proposal, error) and with plain-English tests wired both ways. Agents can turn this pattern into reusable skills.
- **Human-owned spec folders**: splitting code into agent-owned engine code and a readable, linted human folder restores comprehension that pure vibe coding lost.

**Org shape: shared factories over personal setups.** McKinsey (Nov 2026) finds the top 20–25% of enterprises at ~2x end-to-end gains, while most see 10–20%. Cognition claims 40x PR throughput with 2.7x headcount. Ramp says ~75% of its code ships via Inspect, and Google says AI writes ~75% of its new code. Common practices:
- **Cadence and teams:** one- to two-day loops with agents on a night shift, and 2–4 person definer/builder pods.
- **Shared, centrally governed agents:** declarative Terraform-style factory configs (Warp), public sessions as training, and event triggers on PR open.
- **Curated skills:** a few chosen skills rather than ~1,700 options, plus golden examples.
- **Verification:** standards encoded at every stage; inner loops (build, lint, type, headless browser) and outer loops (A/B tests, conversions); online evals scored by agents.
- **Self-testing environments:** Docker Compose services, hourly snapshots, checkpointed sandboxes (~230 ms start), and skills the agent maintains itself.
- **Design and accessibility rules encoded into agents** as bottlenecks move to parallel teams.

**Models and tools (Nov 2026).** Gemini 4 Hydrogen scores ~60% on Terminal Bench 4, versus ~20% for Gemini 3.8 Flash. GPT-6.1 Sol and GPT-6 Astra offer Ultrafast mode (8x faster at 6x cost), which suits hot-reload UI iteration. Codex Cloud v2 sets up warm multi-repo environments automatically. Google Antigravity supports Markdown subagents and scheduled automations. Harnesses are getting simpler: Pi's tools stayed unchanged for a year while capability grew, and agents rely mostly on Bash.
