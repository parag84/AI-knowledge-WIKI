# MCP & tools

> Model Context Protocol, tool use, function calling, connectors, agent-to-tool interfaces.

_18 active · 0 stale · synthesis updated 2026-11-22_

## Current best understanding

**Approval-first tool UX is now shipping in mainstream products (Nov 2026).** Claude's interactive connectors, rolling out on all plans as of 2026-11-18, open third-party apps in full beside the chat. The user can edit directly or ask Claude to edit, approves every action, and Claude works within each person's existing permissions. Scribant (2026-11-17) uses the same execution-gate pattern: the agent pipeline is read-only, it produces proposal cards, and nothing reaches Google Calendar or Jira until the user clicks Approve. The agent also deliberately stays silent while the speaker talks. Antigravity applies the idea at the agent level by letting you include or exclude tools per subagent, for example read-only reviewer workers. For AX and AI component work, this makes proposal cards, inline approval and scoped tool permissions the baseline UI vocabulary.

**Plugins are becoming the delivery unit for tools.** Codex and ChatGPT plugins (2026-11-17) bundle MCP servers (mostly remote), skills and resources, and are shared across web, desktop and Slack. Plugin extensions can also add sidebar entries, side panels, full-page views, file viewers and composer behaviour. One example is a design-system browser plugin built from a single prompt: its 'add to composer' button and @-mention autocomplete inject component context, so the agent doesn't have to search for it. A related practice (2026-11-21) is to have the agent check which skills or MCP servers to install before starting an integration. Skill curation remains the hard part: about 1,700 skills were found for writing a PRD alone (2026-11-08).

**Designing tool surfaces for agents (Looker CLI, 2026-11-16):**
- Keep MCP servers to about 50 tools or fewer, because every description costs context, and expose APIs with hundreds of endpoints through a CLI with self-discovery ('meta tree', 'meta search').
- Give agents empty JSON body templates to fill rather than asking them to build payloads from scratch.
- Expose fine-grained primitives instead of glue commands.

Code mode, credited to Cloudflare and available in Codex and Pi (2026-11-22), lets agents call tools through JavaScript instead of the context window, with cheap classifier models deciding at each branch. One practitioner (2026-11-19) has moved away from 'Bash is all you need' toward MCP, code mode, skills and progressive disclosure. Other notes:
- Local models such as Qwen 3.5 27B need web search to use tools released after their training cutoff (2026-11-21).
- Small routers such as Gemma 2 2B can handle tool-calling.
- A feared major prompt-injection disaster has not materialised as of Nov 2026, attributed to more injection-resistant models.

## Latest active insights

- Code mode, an idea he credits to Cloudflare, gives the agent JavaScript to run in addition to Bash, and tool calls happen through that code instead of through the context window. Combined with cheap, fast classifier or decision models at each branch, an agent can build on-demand workflows, for example triaging 3,000 support requests in a fraction of the time it previously took. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)

Adding search let a local Qwen model change GPU fan RGB colors after it had failed without search. ([What Runs Where? ## Open questions

- MCP vs CLI: one view caps MCP at about 50 tools and pushes large APIs to CLIs, while another now prefers MCP over CLIs. Which wins for large enterprise APIs and developer portals?
- Will code mode (tool calls via executed JS) replace context-window tool calling broadly, and what does that mean for tool-call UI visibility and approvals?
- How should organisations curate and govern skills and plugins (about 1,700 for one task), and could design-system governance models apply?
- Will plugin UI extension points (sidebar, panels, composer) converge across Codex/ChatGPT, Claude connectors and other hosts, or fragment?
- Is the absence of a major prompt-injection incident durable as agents gain write access through connectors?
