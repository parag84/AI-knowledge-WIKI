# Infra & cost

> Serving, latency, caching, pricing, deployment, observability, cost control.

## Current best understanding

**Cost per task is the core metric (Nov 2026).** Compare models, harnesses and skills on your own real tasks. Plot quality or goal completion against cost, and keep only skills that move completion. Use model jaggedness: route high-volume classification and routing to cheap tiers such as Haiku 5.5. Use Sonnet 5.5 (half Opus price) for well-scoped fixes, Opus 5.5 on medium effort as the Claude Code default, and Fable 5.2 (2x Opus) for loosely defined, multi-milestone work. Speakers claim Gemini 4 Carbon and DeepSeek V4 Flash lead on cost per task. Prompt caching comes first: aim for about 90% cache hits. Anthropic's Messages API now lets you change effort mid-conversation without losing the cache (beta). Raise effort before switching models. Shrink context with these techniques:
- progressive MCP tool disclosure (Neo4j cut 16 tools to a 6-tool core)
- rolling transcript windows (about 86% savings)
- distilled memory (Vertex Memory Bank: about 24 tokens vs about 1,400 for raw RAG)
- deterministic engines such as OpenRewrite (about 40K input tokens down to 500)
- code mode or a bash-only harness, which DeepMind found roughly 2x cheaper per task

**Latency shapes agent UX.** About 100 ms feels instant, 1 s keeps the train of thought, and around 10 s people switch tasks. Yet the median coding-agent turn was 63 s (June 2026). Tool execution, not tokens per second, increasingly dominates. Design patterns that follow from this:
- Acknowledge immediately and move slow work off the hot path.
- Use MCP tasks (a task ID plus a notification) instead of having the model poll.
- Offer speed modes such as OpenAI Ultrafast (8x faster at 6x cost), mainly for hot-reload UI iteration.

Durable agents checkpoint after every turn. Lovable reports about 230 ms sandbox start, about 700 deploys a day and agents running 10+ hours. Agents that can suspend and resume can also use cheaper flex-scheduled inference.

**Infra and governance.** For parallel agents, discrete GPUs with batching (RTX Pro 6000 at about 1,300 tok/s across 50 requests) beat unified-memory Macs. Dynamic quantization keeps about 94% accuracy at 4-bit. Agents can tune vLLM configs with Optuna: about 2x throughput on R1 Distill and +17.5% goodput on GPT-OSS 120B. Arm argues tooling and orchestration are CPU-heavy, and the speaker claims AI tokens already outnumber human tokens about 7x. Operational guardrails:
- Give agents explicit spend and concurrency budgets. A CI agent fell from about $32/h to $16/h on GPT-6 Sol, and a forgotten instance cost about $1,000 overnight.
- Enforce boundaries and gates in code, not prompts.
- Reuse versioned datasets (about 10x faster).
- Record traces centrally to track cost, throughput and automation. Those traces can also train small specialized models (Airbnb: 2B parameters at 1% of the cost).

## Latest active insights

- Code mode, an idea he credits to Cloudflare, gives the agent JavaScript to run in addition to Bash, and tool calls happen through that code instead of through the context window. Combined with cheap, fast classifier or decision models at each branch, an agent can build on-demand workflows, for example triaging 3,000 support requests in a fraction of the time it previously took. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)
- Durable agents should be able to suspend and resume, including their sandbox, so they can restart themselves on long overnight runs and take advantage of cheaper flex-scheduled inference, where minutes can pass with no tokens arriving. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)
- Basic plumbing is a real agent failure mode: listing a multi-million-object bucket with AWS CLI or rclone can take minutes to an hour, and an agent session left cloud instances running, adding about $1,000 overnight. ([Data Agents over S3: Build the Missing Semantic Layer for Files - Dmitry Petrov, DataChain](../videos/2026-11-22-data-agents-over-s3-build-the-missing-semantic-layer-for-fil.md), 2026-11-22, relevance 3/5)
- Reusing a previously saved, versioned dataset let the agent answer 'which tasks have the most usable videos' in about 3 minutes versus roughly 30 minutes (10 machines plus extra minutes) when computed from scratch, a ~10x saving that grows to hours at terabyte scale. ([Data Agents over S3: Build the Missing Semantic Layer for Files - Dmitry Petrov, DataChain](../videos/2026-11-22-data-agents-over-s3-build-the-missing-semantic-layer-for-fil.md), 2026-11-22, relevance 3/5)
- Your own agent traces from frontier models can feed an eval, synthetic-data and RL pipeline that trains a small specialized model, which can reach frontier quality at a fraction of the cost. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- Uniform 4-bit quantization can wreck a model. Dynamic, layer-aware quantization keeps heavily used layers at higher precision, and quantized-model recall has improved sharply as a result. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- Choose hardware by workload. Prefill is compute-bound and decode is memory-bandwidth-bound. For parallel agent requests, a discrete GPU with batching vastly outperforms Macs and unified-memory boxes, which run requests sequentially. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- Agent workloads are often bottlenecked by waiting on tool execution such as shell commands rather than tokens per second, so modest hardware can still be useful for agents. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- LiteRT.js runs general ML models such as embedding models, while LiteRT-LM.js runs LLMs. Both delegate ops across WebGPU and Wasm execution backends and are imported as a plain JS library, needing fewer than 20 lines to load and run Gemma 4. ([Web AI at the Edge: Local Vector Search, Gemma 4, & hybrid cloud routing](../videos/2026-11-20-web-ai-at-the-edge-local-vector-search-gemma-4-hybrid-cloud.md), 2026-11-20, relevance 4/5)
- The recommended hybrid flow runs a quick on-device benchmark first and delegates to the cloud if it fails. If it passes, the app still uses the cloud while the model downloads, then switches to local and can expose a toggle such as 'privacy mode now available' or an offline mode. ([Web AI at the Edge: Local Vector Search, Gemma 4, & hybrid cloud routing](../videos/2026-11-20-web-ai-at-the-edge-local-vector-search-gemma-4-hybrid-cloud.md), 2026-11-20, relevance 4/5)

Pairing it with a local Gemma 4 gives fully client-side RAG with no data leaving the device and no per-token cost, which suits medical, legal and finance use cases. Structural collisions are skipped and logged to Cloud Logging, and unmirrored Lustre directories are never touched. - In a public thread, a skeptical user's bug report turned into a collaborative fix: the agent traced the errors to the OTel exporter calling fetch without reading or cancelling the response body on Cloudflare Workers, and patched it to explicitly cancel the body. ([How to build an agent that builds the culture — Zach Bruggeman, Ramp](../videos/2026-11-20-how-to-build-an-agent-that-builds-the-culture-zach-bruggeman.md), 2026-11-20, relevance 4/5)
- Progressive disclosure for MCP: tools/list returns a whole catalog and causes context bloat, token cost and wrong-tool selection; Neo4j's agent memory server cut 16 exposed tools to a 6-tool core profile with extended tools revealed on demand. Rubric: model-chosen actions are tools, reusable context is a resource, procedures are skills, must-always-happen steps are invisible plumbing, and who-may-act is authorization. ([20 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-20-20-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-20, relevance 4/5)
- Factory metrics should go beyond DORA measures like cycle time to include degree of automation (human interactions per PR), throughput and cost. These come from central recording, with no per-laptop installs needed. ([Engineer Your Coding Agents Like Any Other System — Zach Lloyd, Warp](../videos/2026-11-20-engineer-your-coding-agents-like-any-other-system-zach-lloyd.md), 2026-11-20, relevance 3/5)
- Model and harness leaderboards don't settle which configuration is best for you. Build a benchmark from your own real tasks and replay it across models, harnesses, skill sets and factory configs, then plot cost against quality and aim for the low-cost, high-quality quadrant. ([Engineer Your Coding Agents Like Any Other System — Zach Lloyd, Warp](../videos/2026-11-20-engineer-your-coding-agents-like-any-other-system-zach-lloyd.md), 2026-11-20, relevance 3/5)
- Lloyd recommends a layered stack. From the bottom up: factories as code, data and context (record all conversations, artifacts, videos and screenshots), sandboxed multi-platform compute, swappable inference (multiple models and harnesses), orchestration, and an API/MCP-first surface that integrates with Slack, Linear, Jira and GitHub. ([Engineer Your Coding Agents Like Any Other System — Zach Lloyd, Warp](../videos/2026-11-20-engineer-your-coding-agents-like-any-other-system-zach-lloyd.md), 2026-11-20, relevance 3/5)
- Local, interactive, one-at-a-time prompting caps agent throughput at human speed. Per-developer setups (own models, skills, MCPs) also make cost efficiency, security and governance hard to manage centrally. ([Engineer Your Coding Agents Like Any Other System — Zach Lloyd, Warp](../videos/2026-11-20-engineer-your-coding-agents-like-any-other-system-zach-lloyd.md), 2026-11-20, relevance 3/5)
- For small on-device models, avoid exposing 100+ tools; use contextual or hierarchical tool loading by domain, short categorical schemas, and a pre-routing classifier that calls a tool at high confidence (~0.85) and asks for clarification at low confidence. ([19 Nov - MCP Dev Summit Nairobi 2026 Livestream](../videos/2026-11-19-19-nov-mcp-dev-summit-nairobi-2026-livestream.md), 2026-11-19, relevance 3/5)
