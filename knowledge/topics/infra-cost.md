# Infra & cost

> Serving, latency, caching, pricing, deployment, observability, cost control.

_35 active · 0 stale · synthesis updated 2026-11-22_

## Current best understanding

**For AX and UI work (Nov 2026):** cost and latency are now product-design choices. Client-side inference is practical. LiteRT.js and LiteRT-LM.js run embedding models and Gemma 4 in the browser over WebGPU/Wasm in under 20 lines, with WebNN NPU access in preview. VectorSearch.js plus EmbeddingGemma searches about 100k paragraphs in about 100 ms, enabling fully local RAG with no per-token cost. The recommended hybrid flow is a UX pattern in its own right: run a quick on-device benchmark, use the cloud while the model downloads, then switch to local and surface a 'privacy mode now available' or offline toggle. For iteration, a dev-only inspector route with state presets (welcome, thinking, proposal, error) avoids burning model calls on AI-dependent UI states. OpenAI's Ultrafast (Oct 2026, GPT-6.1 Sol / GPT-6 Astra) is 8x faster at 6x the cost and pays off mainly for hot-reload UI iteration. Vendors now headline cost-per-task: Gemini 4 Carbon (Nov 2026) claims #1 on Cursor Bench at 3.3x cheaper than the runner-up.

**Long-running agents and context economics:** agents increasingly run for hours. Lovable has removed its 30-minute agent limit and deploys about 700 times a day using stateless workers and per-turn sandbox checkpoints (about 230 ms start, copy-on-write forks). Durable agents that suspend and resume can use flex-scheduled inference at a steep discount, which implies UX for delayed, asynchronous progress. Token cost falls with tighter context. Examples include:
- a 40-word rolling window that cut classifier tokens about 86%;
- Vertex AI Memory Bank injecting about 24 tokens versus about 1,400 for raw RAG;
- isolated-context subagents (Antigravity);
- semantic or rule-based compaction;
- Cloudflare-style code mode, where tool calls run in JS instead of the context window, with cheap classifier models at each branch.

**Serving and measurement:** dynamic, layer-aware quantization (Unsloth; GLM 5.3 at 4-bit keeps about 94% accuracy) and distilling your own frontier traces into small models make cheap specialized models viable. Airbnb reports a 2B model at frontier quality for 1% of the cost. Pick hardware by workload: batched discrete GPUs suit parallel agents, though many agents wait on tool execution more than on tokens. Measuring impact is still the least mature area. The advice is to benchmark your own tasks across models and harnesses and plot cost against quality. Track automation (human interactions per PR), throughput and cost beyond DORA, and some teams use AI to route tokens to the highest-value work.

## Latest active insights

- Code mode, an idea he credits to Cloudflare, gives the agent JavaScript to run in addition to Bash, and tool calls happen through that code instead of through the context window. Combined with cheap, fast classifier or decision models at each branch, an agent can build on-demand workflows, for example triaging 3,000 support requests in a fraction of the time it previously took. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)
- Durable agents should be able to suspend and resume, including their sandbox, so they can restart themselves on long overnight runs and take advantage of cheaper flex-scheduled inference, where minutes can pass with no tokens arriving. ([Build the Workshop Before the Software Factory — Armin Ronacher, Earendil](../videos/2026-11-22-build-the-workshop-before-the-software-factory-armin-ronache.md), 2026-11-22, relevance 4/5)
- Your own agent traces from frontier models can feed an eval, synthetic-data and RL pipeline that trains a small specialized model, which can reach frontier quality at a fraction of the cost. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- Uniform 4-bit quantization can wreck a model. Dynamic, layer-aware quantization keeps heavily used layers at higher precision, and quantized-model recall has improved sharply as a result. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
- Choose hardware by workload. Prefill is compute-bound and decode is memory-bandwidth-bound. For parallel agent requests, a discrete GPU with batching vastly outperforms Macs and unified-memory boxes, which run requests sequentially. ([What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](../videos/2026-11-21-what-runs-where-local-ai-in-production-ahmad-osman-osmantic.md), 2026-11-21, relevance 2/5)
